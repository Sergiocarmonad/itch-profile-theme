STEP 1

Profile theme

Open your profile (yourname.itch.io) while logged in and click Edit theme. Paste these values, then save. Body text is the dim green and links the bright green, so your game titles light up like selectable menu items.

100%

STEP 3 · OPTIONAL

      
Vending machine CSS

      
Turns your games column into a vending machine. It has a 自動販売機 ("vending machine") neon sign on top, a glass front with lit shelves, and each game as a glossy product in a numbered slot. On the right is a coin panel with an INSERT COIN display and a keypad, and at the bottom a PUSH tray. Hovering a slot lifts the product, lights its button in magenta, cyan or orange, and the label changes to PLAY. The terminal extras stay too: stencil name, magenta tube under it, scanlines. On phones the coin panel is hidden so the games keep the width.

    

    

    
Needs approval. itch.io turns CSS on per account. Contact itch.io support, say you want to restyle your profile's game grid and header in ways the theme editor can't, and confirm you'll keep the page accessible and leave itch's own UI and footer alone. Once it's on, a CSS box appears in the profile theme editor.

    
Selector caveat. itch.io only documents stable selectors for game and jam pages. The profile selectors below come from the live profile page markup, and the preview above uses that same markup, so it should match closely. A future itch.io update could still break them; if that happens the games fall back to a normal grid.
