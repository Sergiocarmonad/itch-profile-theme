STEP 1

Profile theme

Open your profile (yourname.itch.io) while logged in and click Edit theme. Paste these values, then save. Body text is the dim green and links the bright green, so your game titles light up like selectable menu items.

Font
IBM Plex Mono (type the name into the font search)
Font size
100%
Corners
Square, radius 0 (the portfolio has no rounded corners)
Layout
Column (bio and links on the left, games on the right)
Banner
None for now (your name shows as text instead)

STEP 2

Bio and links

In Edit profile, add your portfolio and socials as profile links, then paste this into the bio box (switch it to HTML if it offers that). Swap in your own lines.

STEP 3 · OPTIONAL

      
Custom CSS

      
Adds the stencil name with a WHOAMI prompt, scanlines, and the neon: a magenta tube under your name, a small buzzing 営業中 ("open for business") sign, cyan on link hover, and game covers that glow magenta, cyan or orange in turn. Green stays the main color. Tick Show step 3 extras above and hover the games to compare.

    

    

    
Needs approval. itch.io turns CSS on per account. Contact itch.io support, say you want scanlines, a header font and hover glows that the theme editor can't do, and confirm you'll keep the page accessible and leave itch's own UI and footer alone. Once it's on, a CSS box appears in the profile theme editor.

    
Selector caveat. itch.io only documents stable selectors for game and jam pages. The profile selectors below come from the live profile page markup, so a future itch.io update could break them. Nothing breaks badly if that happens; the effects just stop showing.
