# Itch Profile Theme

A lighter version of my Neon Noir portfolio theme (green phosphor terminal) for my itch.io profile, with a few neon accents, and the games column restyled as a neon vending machine.

`itch-page-kit.html` is a preview of the profile plus everything to copy into itch.io:

1. **Profile theme**: colors, font, corners and layout for itch.io's Edit theme panel.
2. **Bio**: HTML for the profile bio.
3. **Custom CSS (optional)**: the vending machine, scanlines, stencil name and neon accents. The preview runs this exact CSS on a copy of the profile markup. itch.io only enables CSS per account on request.

Open the HTML file in a browser to view it.
