# Itch Profile Theme

A lighter version of my Neon Noir portfolio theme (green phosphor terminal) for my itch.io profile, with a few neon accents.

`itch-page-kit.html` is a preview of the profile plus everything to copy into itch.io:

1. **Profile theme**: colors, font, corners and layout for itch.io's Edit theme panel.
2. **Bio**: HTML for the profile bio.
3. **Custom CSS (optional)**: scanlines, stencil name, neon accents. itch.io only enables CSS per account on request.

Open the HTML file in a browser to view it.
